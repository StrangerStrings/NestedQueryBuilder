# queryBuilder

A visual query builder built with Vue 3, Vite, TypeScript, and Pinia.

## Database targets

Build filters visually for PostgreSQL, MySQL 8.4, MariaDB 11.4 LTS, Elasticsearch, and MongoDB. Export as SQL or JSON, import supported filters, and load schemas for field suggestions.

Choose a target in **Databases**. Switching clears the current query and schema suggestions.

For supported syntax and limitations, see the [MySQL](docs/mysql-capabilities.md), [MariaDB](docs/mariadb-capabilities.md), and [Elasticsearch](docs/elasticsearch-capabilities.md) guides.

## Type Support for `.vue` Imports in TS

TypeScript cannot handle type information for `.vue` imports by default, so we replace the `tsc` CLI with `vue-tsc` for type checking. In editors, we need [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) to make the TypeScript language service aware of `.vue` types.
