## Project overview

- This is a Vue 3 application built with Vite and TypeScript.
- It is a visual query builder with PostgreSQL and Elasticsearch database modes.
- Application state lives in Pinia stores;


## Project rules

- Add a short comment above functions you create or change.
- Do not write or change tests unless asked.
- Run tests, formatting, linting, type checks, or builds only when asked.
- When asked to 'check', use a separate agent if available to run the project's formatting, linting, and Vue/TypeScript type checks using existing scripts, then fix any errors. Finally build the project
- Keep changes small and focused. Avoid unnecessary abstractions, dependencies, and unrelated refactoring.
